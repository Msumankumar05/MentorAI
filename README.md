# MentorAI 🎓

An AI-powered chatbot for students focused on exam preparation and coding learning.

## ✨ Features

- 🤖 AI Chat with multiple modes (Exam Focus, Coding Mentor, Syllabus Mode)
- 📁 File Upload (PDF, DOCX, TXT) with text extraction
- 🎤 Voice Input (Speech-to-Text)
- 🔊 Text-to-Speech for AI responses
- 📥 PDF Export of chats and summaries
- 🌙 Beautiful Dark Mode UI with glassmorphism
- 💻 Syntax highlighting for code blocks
- 📚 Chat history and management
